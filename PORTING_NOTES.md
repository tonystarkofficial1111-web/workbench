# Workbench 5.59.4 -> React/TS port: working notes

Source of truth: `C:\Users\antho\Downloads\Workbench_5_59_4.html` (13.8 MB; the port started from 5.59.0 and was synced to 5.59.4, see the end).
Split into pieces by script in `_orig/` (`_index.txt` lists every <style>/<script> block in document order).
`_orig/page.html` = body skeleton with blocks replaced by `__BLOCK__` and base64 stripped.

## Decisions (confirmed with user)
- Pixel/behavior parity, ALL tabs and features. Keep both AFK videos embedded. Bundle fonts + three.js; keep online APIs (Gemini/YouTube/Invidious).
- Keep identical localStorage/IndexedDB keys+formats; add export/import.
- TypeScript. React shell + plain-TS engine modules (canvas/three loops mounted via refs).
- Output: `dist/Workbench.html` (single file, works on file:// in Chrome). Toolchain: bun only (`bun run build.ts`).

## Build
- `build.ts`: Bun.build iife -> inlines JS + CSS (fonts as data URLs) into `src/index.html` template.
- CSS is kept verbatim in `src/styles/NN-xxx.css` in original document order (cascade parity). Three rules were invalid CSS in the original
  (stray `<style>` prefix / `body.` typo) so browsers dropped them; they are dropped in the port too.

### Block World: glue bugs found by driving the original and the port side by side
The engine itself is byte-identical to the original; every difference was in the glue around it:
1. **Squashed picture** - `game:resize` was sent before React had made the Block World section visible, so the renderer sized itself from
   the window instead of the section and the canvas buffer had the wrong aspect. `WorldTab` now sends it in a layout effect after the commit.
2. **Coins never saved** - boss / dawn rewards called the page's `wbSaveProfile()`, which does not exist here; it threw inside a try/catch.
   The converter now routes it to `commitProfile()` (and no longer writes the React-owned coin counter by hand).
3. **Export / Import world ran twice** - the engine attached its own listeners to the User / Saves buttons that React already wires
   (two downloads, the file imported twice, status text written into a React node). The converter drops the engine's copy.
4. **Start > Block World card did nothing** (a quirk of the original: it looked for a tab button that Block World does not have).
   It now opens Block World at its mode picker, like Arcade > Block World.
Everything else was checked with real mouse-style events in both builds (and in the obfuscated build via `build.ts --dbg`): all building and
defense buttons place and charge wood, 1x / 10x speed, Shaders, Follow the King, Instructions, Record clip, Back to Arcade, Resume, the mode
picker, the Workshop / Market / Armory menus, and the classic Save / Load / Command mode / Buildings controls.
Still the original's behaviour: Legacy and the classic sandbox start with Shaders off (Infinite switches them on by itself); the classic
hotbar is dimmed and not clickable in Command mode (`#hotbar.dim{pointer-events:none}`) and only works after switching to Build mode.
